## ক্লাস নেওয়ার আগে (ইনস্ট্রাক্টরের জন্য)

1. রিপোর রুট থেকে AI অ্যাসিস্ট্যান্ট চালান — যাতে AI `backend/src` আর `docs/mobile-app-prompts.md` পড়তে পারে।
2. প্রতিটি ক্লাসের শুরুতে ব্যাকএন্ড চালু রাখুন (`cd backend && npm run dev`) — OTP ব্যাকএন্ড টার্মিনালে প্রিন্ট হয়।
3. দুটি টেস্ট অ্যাকাউন্ট রাখুন (দুটি আলাদা ফোন নম্বর) এবং একটি **অ্যাডমিন** অ্যাকাউন্ট (`backend/src/scripts/seedAdmin.ts`) — KYC ও বিজ্ঞাপন অ্যাপ্রুভ করতে ওয়েবের `/admin` প্যানেল লাগবে।
4. প্রতিটি প্রম্পটের পর: অ্যাপ চালান → টেস্ট করুন → `npx tsc --noEmit` → কমিট। স্টুডেন্টদেরও এই অভ্যাস করান।
5. AI ভুল করলে সেটাও ক্লাসে দেখান — "AI-এর আউটপুট কীভাবে রিভিউ করতে হয়" এটাই এই কোর্সের সবচেয়ে গুরুত্বপূর্ণ স্কিল।
